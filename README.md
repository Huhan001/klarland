# Klarland

Klarland is a focused study app for understanding the *Leben in Deutschland* exam catalogue while learning German in context.

The Next.js app contains the complete Hessen learning sequence:

- **Questions 1–300** — the general Germany catalogue
- **Questions 301–310** — the 10 Hessen state questions
- **Wörter** — a shared German-to-English word lexicon
- **Wortgruppen** — full question and answer meaning in context
- **Wiederholen** — a personal review queue stored locally in the browser

There is no database, account, or backend. Progress and the last open card use `localStorage` only.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run check:catalogue
npm run lint
npm run build
```

## Catalogue pipeline

The committed `src/data/general-questions.json` is generated by `scripts/validate_catalogue.py`. The script extracts current German wording and all four options from the BAMF PDF, resolves the correct answer against two independent datasets, and writes only the official German question and matching official answer into the app data.

The optional `scripts/build_lexicon.py` helper uses a local Argos Translate German-to-English model to rebuild the shared static vocabulary file. Argos is not a runtime dependency of the website.

## Source

The German wording and illustrations come from the [BAMF Gesamtfragenkatalog zum Test „Leben in Deutschland“ und zum „Einbürgerungstest“](https://www.bamf.de/SharedDocs/Anlagen/DE/Integration/Einbuergerung/gesamtfragenkatalog-lebenindeutschland.html), catalogue dated 07.05.2025.

German exam content remains separate from the translation layer. Translations never determine an answer shown to learners unless an older answer has first been detected as absent from the current BAMF options and independently resolved.
